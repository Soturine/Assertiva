# Assertiva v1.1.0 — Context-Aware, Adaptive & Continuous Test Assurance

Released 2026-11-27 from PR #13 (candidate `1.1.0rc1`). Distribution: this GitHub Release (wheel and sdist with SHA-256 checksums); not PyPI.

**What exactly does this green prove — measured against what the project was meant to do?**

1.0 answered what the tests really executed and proved. 1.1 adds the other side: the documents, contracts and diagrams that define the intended behavior, how far the tests protect it, and how to get evidence for stacks the engine does not run.

## Highlights

- **Documentary context and traceability.** The auditing agent reads the sources that define behavior — natively, including figures — and attaches what it read and the behaviors it traced to tests. The engine verifies paths, digests, page counts, that each citation falls inside what was read, and that no behavior is claimed stronger than its evidence. A demo shows a rule that exists only as an image in a PDF: invisible to text extraction and to the engine alone, found by visual reading, protected by an improved test proven with negative controls.
- **Stacks without an adapter.** A protocol for finding and running a project's own tools safely (current docs, consent, a download stage separate from an offline confined run) and recording each run as an external execution receipt that the engine checks but never runs. Demonstrated on Ruby (minitest) and .NET 10 (xUnit, Stryker.NET 5.1.0).
- **Feedback about Assertiva from every run.** `audit.dogfood.json`/`.md` beside each report, local and sanitized, without Portfolio, account or network; `assertiva portfolio import-feedback` consolidates files from any installation, idempotently.
- **Independent reviews** are recorded with their independence and consent; no provider is called by the engine.
- Integrates PR #11 (missing build backend attributed to the environment) and PR #12 (oracle and evidence review).

## Limits

- The engine does not read documents: reading is agent-reported; a digest proves which bytes were cited, not that they were understood.
- No native adapter for .NET, Ruby, Go or C++; external runs are `AGENT_EXTERNAL`.
- No agent evaluation was run for this release: the blind multimodal reading and PR #12's evaluation cases are NOT_RUN (no eval budget was approved). No agent-evaluation result is claimed.
- Office formats, OCR, C++ and calls to any provider were not exercised.
