# Test Smells and Weak-Test Signals

Smells are investigation prompts, not automatic failures.

Candidate signals:
- no assertion or effectively no observable verification;
- assertion roulette / unclear assertions;
- eager or overloaded test;
- mystery guest / hidden external dependency;
- oversized/general fixture;
- order dependence;
- sleeps/waits without condition;
- excessive mocking;
- implementation-detail assertions;
- giant snapshots;
- semantic duplication;
- ignored/quarantined failures;
- retry dependence;
- production and test code sharing the same oracle;
- expected output generated by the same logic under test.

Connect each smell to actual risk/evidence before recommending change.
