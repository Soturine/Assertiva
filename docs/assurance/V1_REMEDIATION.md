# v1.0 remediation ledger

Every item lists its reproducer, the change, the tests and the evidence. *Fail-before* means: the new tests from
`HEAD`, run against the code of the integrated base `bb36fe1` (which already contains PRs #6-#8 and both Prescripta
branches), in a disposable worktree. 25 of the 27 new tests failed there and all 27 pass on `HEAD`. Of the two that
passed on the base, one is a control by design (`test_controls_anything_that_points_to_pytest_keeps_pytest`). The
other, `test_the_gate_decision_matrix`, passed only because the base worktree loaded the new `assertiva/gate.py` from
the main checkout through the editable install's import finder. That is the same shadowing that `source_identity`
exists to detect. The gate is a new module, so on the base it does not exist. Every other new test ran against base
code (checked: `cosmic_ray.tests_ran` is absent there).

The status words are FIXED, PARTIAL, DEFERRED, ACCEPTED_LIMITATION and NOT_CHANGED. Machine-readable copy:
